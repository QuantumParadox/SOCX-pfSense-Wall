# Lenovo ThinkCentre M910t i7-7700 pfSense Notes

This SOCX install has been tested on:

- System: Lenovo ThinkCentre M910t
- Type/model: 10MM000HUS
- CPU: Intel Core i7-7700
- CPU topology: 4 cores / 8 threads
- pfSense detected CPU: `Intel(R) Core(TM) i7-7700 CPU @ 3.60GHz`
- BIOS observed on the appliance: `M1AKT59A`, release date `2023-10-27`, SMBIOS BIOS revision `1.59`
- AES-NI: detected and loaded
- Thermal sensor driver: `coretemp`
- Speed Shift / hwpstate: enabled

## SOCX Hardware Profile

SOCX reads an optional profile at:

```sh
/usr/local/etc/socx_system_profile.env
```

An example is provided in:

```sh
config/socx_system_profile.env.example
```

The browser `/health` and `/story` pages use this profile plus live pfSense telemetry to show hardware headroom: CPU model, cores/threads, hottest core, frequency, AES-NI, powerd, and thermal thresholds.

## Thermal Thresholds

For this i7-7700 M910t build, the pfSense dashboard thermal widget was tuned from the old conservative `60C/70C` warning/critical thresholds to:

- Warning: `75C`
- Critical: `85C`

This keeps normal i7 load spikes from looking like false emergencies while still warning before the CPU gets uncomfortable. A 45-second, 8-worker OpenSSL AES-GCM burn-in peaked at `74C`, so `75C` is a cleaner warning point for this chassis.

## Post-Upgrade Checks

```sh
sysctl -n hw.model
sysctl -n hw.ncpu
sysctl -a | egrep '^dev.cpu.[0-9]+.(temperature|freq):'
kldstat | egrep 'aesni|coretemp|cpuctl'
service powerd status
socx v1-check
socx story
```

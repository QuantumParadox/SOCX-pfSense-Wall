# SOCX pfSense Wall v0.2 Release Notes

SOCX v0.2 turns the wall from a passive display into a small read-only SOC cockpit. The terminal wall keeps the neon btop-style layout, while the browser wall gains a Command Center card for live verdicts and operator next steps.

## Highlights

- Truthful WAN, VPN, DNS, UPS, and Speedtest path status.
- DIRECT and VPN Speedtest profiles, including named VPN path caches.
- Autopilot scoring for normal, watch, degraded, investigate, and incident-style states.
- Pi 3-LLM and MIRANDA bridge awareness for local AI SOC experiments.
- `socx menu`, `socx status`, `socx timeline`, `socx repair`, and `socx explain-screen`.
- `socx history` JSONL trend samples in `/var/db/socx_history.jsonl`.
- Optional `socx notify` webhook hook.
- Browser `/api/command-center` and Command Center card.

## Common Commands

```sh
soc
socweb --host 0.0.0.0 --port 8094
socx status
socx autopilot
socx timeline 60
socx history show
socx repair
socx explain-screen
socx speedtest direct
socx speedtest vpn
```

## Safety Notes

SOCX is designed to be read-only by default. Repair commands restart SOCX collectors and helper daemons, but they do not change firewall rules or block traffic. Incident commands preserve evidence before deeper troubleshooting.

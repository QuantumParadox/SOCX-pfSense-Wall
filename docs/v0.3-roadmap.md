# SOCX v0.3 Autonomy Notes

This milestone focuses on explainability and autonomous read-only operations.

## Added

- `socx why-now` for plain-English SOCX reasoning.
- Four-part Autopilot scoring: network, security, AI, and sensors.
- `socx history trend` for local trend summaries.
- `socx notify rules` for optional webhook alerts.
- `socx mode` presets for different wall situations.
- `socx hosts suggest/apply` for better host naming.
- Repair before/after snapshots in `/tmp/socx-repair-report.txt`.
- Browser Command Center score breakdown and trend label.

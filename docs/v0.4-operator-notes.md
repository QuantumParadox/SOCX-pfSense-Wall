# SOCX v0.4 Operator Notes

SOCX v0.4 focuses on evidence, history visibility, and optional alert scheduling.

## New Commands

```sh
socx snapshot
socx notify-cron status
socx notify-cron install
socx notify-cron remove
```

`socx snapshot` creates `/root/socx-snapshots/<timestamp>/` and a compressed archive with status, why-now, history trend, timeline, Speedtest path truth, topology, unknown-service review, key cache files, web Command Center JSON, web history JSON, and checksums.

`socx notify-cron install` schedules `socx notify rules` every five minutes. It is safe to leave disabled until `SOCX_NOTIFY_WEBHOOK_URL` is configured.

## Web Additions

- `/api/history` returns recent JSONL history rows and a trend summary.
- The browser Command Center now draws a small Autopilot score sparkline from the history file.

## Read-Only Boundary

These additions do not modify firewall policy. They collect, explain, schedule optional notifications, and preserve evidence.

# SOCX v1.0.0-rc2 Release Notes

SOCX v1.0.0-rc2 is the Data Truth and Pi-fleet hardening checkpoint for the pfSense wall project. It keeps the existing neon btop-style wall layout, then makes collector freshness and meaningful state changes visible.

## Highlights

- Data Truth freshness scoring shows whether key signals are live, stale, waiting, inactive, or degraded.
- What Changed tracks meaningful shifts such as Speedtest path state, Pi fleet status, incident verdicts, top blocked source, learned-normal anomalies, and UPS freshness.
- Pi fleet discovery refreshes safely from the browser collector when the Pi cache is missing or stale.
- `socx-pi-nodes` now exports `online`, `count`, and `state` so `socx v1-check` agrees with the browser API.
- Browser detail pages show richer Mission Control cards for Speedtest, Devices, Incidents, and AI.
- The AI detail page presents Pi role health, temperature, load, memory, service, and autonomy summaries in human-readable rows.

## Operator Checks

```sh
socx v1-check
socx status
socx-report weekly
socx pi-nodes
```

Expected warning examples:

- VPN Speedtest may show inactive when the VPN path is intentionally off.
- Data Truth may show WATCH when a collector is intentionally inactive, such as VPN Speedtest while off VPN.

SOCX remains read-only for firewall policy by default. It collects, summarizes, and recommends; it does not silently change pfSense rules.

# SOCX v1.0.0-rc3 Release Notes

SOCX v1.0.0-rc3 is the release-health and clarity pass. It focuses on making the project cleaner to maintain and making the wall explain why it trusts, warns, or distrusts its own data.

## Highlights

- Added `/health`, a browser Release Health page.
- Added `/api/health`, a fixed allowlist endpoint for readiness and service health checks.
- Added plain-English Data Truth reasons, for example why the wall is in `WATCH`.
- Added Pi AI role visibility for triage, evidence, and action roles when exposed by the Pi health endpoint.
- Cleaned repo status noise by ignoring generated Python bytecode and local `work/` scratch output.

```sh

curl http://127.0.0.1:8094/api/health
```

SOCX remains read-only for firewall policy by default. The new health endpoint runs fixed SOCX checks only; it does not expose arbitrary shell execution.

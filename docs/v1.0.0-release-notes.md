# SOCX v1.0.0 Release Notes

SOCX v1.0.0 is the first stable release of the pfSense SOC wall. It combines the terminal/tmux wall, browser wall, detail pages, Data Truth freshness scoring, Pi 5/Pi 4 visibility, Speedtest path truth, and evidence-preserving operator tools.

## Highlights

- Neon btop-style terminal wall for pfSense.
- Browser SOC wall on port `8094`.
- Focused detail pages for Speedtest, Devices, Incidents, Why Blocked, AI, and Release Health.
- Data Truth scoring explains whether SOCX data is live, stale, waiting, inactive, or degraded.
- `/why` explains recent block context for IPs, domains, and ports.
- Browser `Bundle` action creates a read-only incident evidence bundle.
- Pi Fleet shows Pi 5 AI and Pi 4 telemetry state.
- Speedtest separates active, direct, client, router, and VPN path truth.
- Release Health checks verify wall/session/API/readiness state.


## Safety

SOCX v1.0.0 is read-only for firewall policy by default. Browser actions run fixed allowlisted commands for status, evidence, health, and analysis. Rule recommendations remain approval-only and do not silently change pfSense configuration.

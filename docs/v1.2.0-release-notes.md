# SOCX v1.2.0 Operator Intelligence

SOCX v1.2 turns the wall from a live display into a read-only operator intelligence layer.

## Highlights

- New `/mission` browser page.
- New `/api/mission` endpoint.
- New `socx mission` terminal command.
- Mission summary answers:
  - What changed
  - What matters
  - What to check
  - What is probably noise
- Terminal wall Event Feed now rotates compact Mission, VPN detail, Pi AI role, thermal confidence, and noise-summary events.
- Release Health now checks for the current `READY FOR SOCX` readiness text.

## Safe By Design

SOCX Mission does not change firewall rules, DNSBL policy, IDS suppressions, VPN routing, or pfSense packages. It turns existing evidence into operator guidance and points to safe review commands.

## Useful Commands

```sh
socx mission
socx status
socx why-now
socx snapshot
socx incident quick
```

## Browser Pages

- `/mission` - operator intelligence summary
- `/story` - daily narrative
- `/health` - release and collector truth
- `/why` - explain block context
- `/speedtest` - DIRECT/VPN speed truth
- `/devices` - Label Brain and asset watch
- `/ai` - Pi/MIRANDA AI role visibility

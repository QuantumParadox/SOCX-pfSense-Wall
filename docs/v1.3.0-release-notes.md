# SOCX v1.3.0 - ATT&CK / D3FEND / KEV Intelligence

SOCX v1.3 adds a read-only intelligence layer on top of the existing wall, Mission page, and Pi AI bridge.

## Highlights

- Maps current firewall, DNSBL, IDS, and learned-normal asset drift signals to conservative MITRE ATT&CK context.
- Adds defensive countermeasure names from the D3FEND style of reasoning.
- Checks observed CVEs against the CISA Known Exploited Vulnerabilities catalog when CVEs are present in SOCX evidence.
- Adds `/api/intel` and Mission page cards for priority, disposition, KEV state, ATT&CK/D3FEND rows, and kill-chain story.
- Adds `socx intel` for terminal operators.
- Enriches the Pi/MIRANDA export with the same intelligence object.

## Safety

This release remains read-only. SOCX does not change firewall rules, suppress IDS alerts, allowlist DNSBL domains, or apply response drafts automatically. It produces evidence, mappings, and recommended next checks for a human operator.
